# Python RAG Chatbot - Frontend

Modern, glassmorphic React + Vite user interface for the Python RAG Chatbot application.

## Features
- **ChatGPT-Style Interface**: Real-time rendering, markdown support, and single-click code copy.
- **Python Guardrail Alerts**: Visual notifications when non-Python queries are declined.
- **RAG Context Citation Drawer**: Interactive breakdown of retrieved document pages and similarity chunks.
- **PDF Upload Manager**: Drag-and-drop uploader with real-time indexing feedback.
- **Dark/Light Mode**: Full responsive design system powered by Tailwind CSS & Framer Motion.

## How to Run

1. Install Node.js dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open `http://localhost:5173` in your browser.
